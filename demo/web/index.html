Aller à l'image

Tracé des vaisseaux rétiniens

Cliquez deux points sur un vaisseau d'une image de fond d'œil. Le programme voit l'image comme un graphe dont chaque pixel est un sommet, et suit le vaisseau par le chemin le moins coûteux (algorithme de Dijkstra).

Code source et évaluation. Tout se passe dans votre navigateur : vos images ne quittent pas votre ordinateur.

Préparation de l'application

Première visite : 10 à 40 s, le temps de charger Python dans le navigateur.

Comment faire ? Cliquez un premier point sur un vaisseau, puis un second plus loin sur le même vaisseau. Inutile de viser au pixel près : le point se place tout seul sur le vaisseau le plus proche.

Vous pouvez aussi glisser-déposer votre propre image sur la zone ci-dessus.

Signes de maladies de l'œil

Un réseau de neurones, entraîné sur 6 392 yeux de la base publique ODIR-5K, cherche sur l'image les signes de six maladies : rétinopathie diabétique, glaucome, cataracte, DMLA, rétinopathie hypertensive et myopie forte.

Comment lire ces pourcentages ?

Démonstration de recherche, pas un diagnostic : seul un ophtalmologiste peut diagnostiquer une maladie. Le réseau ne voit qu'une photo, sans l'âge ni les antécédents du patient, et ses pourcentages valent pour une population comme celle des bases d'entraînement (patients consultant en ophtalmologie).

Mesures vasculaires

Un réseau de neurones (U-Net) segmente les vaisseaux, puis le programme mesure leur densité, leur calibre, leur tortuosité et la complexité du réseau. Ces mesures sont étudiées comme marqueurs de santé vasculaire, notamment du risque cardiovasculaire.

Démonstration de recherche, pas un diagnostic. Les deux dernières colonnes viennent de notre étude sur les 20 patients de test : « Fiabilité » indique si la mesure du U-Net classe les patients comme un expert (corrélation de rang, 1 = identique), « Accord entre 2 experts » donne la même valeur pour un second expert humain. Même les experts divergent sur la plupart des marqueurs ; les versions robustes, définies pour que les experts s'accordent mieux, sont plus fiables (voir l'étude).

Détails des mesures

Sur le tracé : part du tracé posée sur un vaisseau annoté (à 2 px près). Chemin de l'expert suivi : part du chemin de référence que le tracé recouvre. F1 : synthèse des deux (1 = parfait). Écart maximal : distance de Fréchet entre les deux courbes, en pixels.

Image

Trois images tirées au hasard parmi les 20 images de test de la base publique DRIVE, annotées par un expert : le tracé et les mesures y sont comparés à l'expert.

Comparer les six prétraitements

Chaque vignette montre ce que « voit » le programme : plus un pixel est clair, plus il ressemble à un vaisseau. Sur les exemples annotés, l'AUC et le MCC mesurent l'accord avec l'expert (1 = parfait). Cliquez une vignette pour l'utiliser dans le tracé. À retenir : la meilleure carte n'est pas toujours celle qui donne le meilleur tracé (analyse complète).
