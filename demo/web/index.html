Aller à l'image

Tracé des vaisseaux rétiniens

Cliquez deux points sur un vaisseau d'une image de fond d'œil. Le programme voit l'image comme un graphe dont chaque pixel est un sommet, et suit le vaisseau par le chemin le moins coûteux (algorithme de Dijkstra).

Code source et évaluation. Tout se passe dans votre navigateur : vos images ne quittent pas votre ordinateur.

Préparation de l'application

Première visite : 10 à 40 s, le temps de charger Python dans le navigateur.

Comment faire ? Cliquez un premier point sur un vaisseau, puis un second plus loin sur le même vaisseau. Inutile de viser au pixel près : le point se place tout seul sur le vaisseau le plus proche.

Vous pouvez aussi glisser-déposer votre propre image sur la zone ci-dessus.

Détails des mesures

Sur le tracé : part du tracé posée sur un vaisseau annoté (à 2 px près). Chemin de l'expert suivi : part du chemin de référence que le tracé recouvre. F1 : synthèse des deux (1 = parfait). Écart maximal : distance de Fréchet entre les deux courbes, en pixels.

Réglages avancés

Plus α est grand, plus traverser le fond coûte cher : le tracé colle aux vaisseaux mais peut faire des détours.

Comparer les six prétraitements

Chaque vignette montre ce que « voit » le programme : plus un pixel est clair, plus il ressemble à un vaisseau. Sur les exemples annotés, l'AUC et le MCC mesurent l'accord avec l'expert (1 = parfait). Cliquez une vignette pour l'utiliser dans le tracé. À retenir : la meilleure carte n'est pas toujours celle qui donne le meilleur tracé (analyse complète).

Exemples : jeu de test public DRIVE (J. Staal et al., Ridge-based vessel segmentation in color images of the retina, IEEE TMI, 2004), chargés depuis un miroir public et non redistribués ici. Code sous licence MIT.
